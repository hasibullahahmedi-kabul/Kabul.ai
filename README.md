# Kabul.ai
# 👁️ Brother Eye AI System

این یک پروژه شبیه‌سازی شده از هوش مصنوعی تاکتیکی بتمن (برادر چشمی) با پایتون است.

## 🚀 قابلیت‌ها
- بینایی ماشین و تشخیص چهره اپراتور مجاز
- اسکرپینگ داده‌های وب برای تحلیل امنیتی
- اتصال به مدل پیشرفته Gemini برای پردازش دستورات استراتژیک
- داشبورد مدیریتی با Streamlit

## 🛠️ نحوه راه‌اندازی
1. ابتدا کتابخانه‌ها را نصب کنید: `pip install -r requirements.txt`
2. کلید Gemini API خود را تنظیم کنید.
3. برنامه را اجرا کنید: `streamlit run main_dashboard.py`
